## 코드 스멜과 인지 부하

코드 스멜은 작동은 하지만 개선의 여지가 있는 코드다. 너무 큰 메서드나 복잡한 switch가 예다. 리팩터링은 코드 스멜을 해결하며 코드를 개선하는 과정이다.

| 코드 스멜 | 인지 부하 |
|---|---|
| 신의 클래스, 긴 메서드 | 효율적인 청킹이 어려움 |
| 많은 매개변수, 복잡한 switch | 작업 기억 용량 초과 |
| 코드 클론, 중복 코드 | 서로 다른 것을 같은 것으로 잘못 묶는 청킹 |

나쁜 이름과 언어적 안티패턴도 코드 이해에 인지 부하를 더한다.

## 복잡한 문제 해결

문제 해결에 도움이 되는 방법으로 장기 기억(LTM) 강화, 자동화, 재활용을 정리했다. 문제 해결은 목표 상태와 달성 조건, 시작 상태, 가능한 방법을 규정하는 규칙을 이해하는 것에서 시작한다.

1. 문제를 이해한다.
2. 계획을 세운다.
3. 계획을 실행한다.

작업 기억(STM)에서 현재 문제의 정보를 가져오고, LTM에서 함수·라이브러리·비슷한 문제에 관한 지식을 검색한다.

## 기억과 학습 부하

기억은 절차적/선언적, 의미적/일화적 유형으로 나눠 볼 수 있다. 정보를 LTM에 저장할 때 생기는 본유적 인지 부하를 고려해 학습 내용을 구조화한다.
