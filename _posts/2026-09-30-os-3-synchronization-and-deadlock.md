# 동기화와 교착상태

- `공유 자원` : 다른 프로세스 혹은 다른 스레드 간에 공유되는 자원
- `임계 구역` : 공유 자원을 사용할 경우 문제가 발생할 수 있는 영역
- `레이스 컨디션` : 동시에 임계 구역의 코드를 실행하여 문제가 발생한 상황 ( 진입시 대기해서 해결 )
  
## 동기화 조건

- 실행 순서 제어 : 올바른 순서로 실행
- 상호 배제 : 동시에 접근하면 안되는 자원을 통제

## 동기화 기법

- `뮤텍스 락` : 임계 구역에 접근하려면 락을 획득, 작업이 끝나면 락을 해제 (한번에 하나의 프로세스)
- `세마포` : Stop, Go 신호로 임계 구역을 관리 임계구역 앞에서 멈춰 있다가 신호를 받고 들어가게됨 (한번에 여러 프로세스)<br>동기화 도구, 동시 실행량/자원 사용량을 제어
  - 변수S : 한번에 진입할 수 있는 프로세스 개수
  - wait함수 : 임계 구역 진입 전 호출
  - signal함수 : 임계 구역 작업 후 호출
- 조건변수와 모니터 
  - 뮤텍스를 통해 들어가도 되는지를 제어, 조건 변수로 내가 원하는 상태인지를 확인, 모니터로 둘을 묶음
  - `모니터` : 공유 자원과 자원 관리용 인터페이스로 구성된 도구

## 교착상태 Deadlock

서로 다른 프로세스가 서로 필요한 자원을 점유한 상태로 대기하며 멈춘 상태

발생조건<br>
- 상호 배제 (Mutual exclusion)
- 점유 상태로 대기 (Hold and wait)
- 선점 불가 (No preemption)
- 순환성 대기 (Circular wait)

해결방안<br>
- 예방 : 필요 조건 4가지 중 하나를 막는다.
- 회피 : 무분별한 자원 할당을 지양
- 검출 후 회복 : 주기적으로 교착 상태 여부를 검사, 자원 선점 혹은 강제종료를 통한 회복
