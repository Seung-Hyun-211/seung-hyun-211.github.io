# 네트워크

네트워크 포톨로지 : 노드사이 연결구조, 망, 트리, 링, 성, 버스형 등

`호스트 Host` : 네트워크를 통해 데이터를 주고받는 장치<br>
`클라이언트 Client` : 요청을 보내는 호스트<br>
`서버 Server` : 응답을 보내는 호스트, 요청을 받아 서비스를 제공하는 호스트


### LAN WAN

LAN local area network : 가정, 기업과 같은 가까운 거리를 연결<br>
WAN wide area network : 원거리 연결<br>
ISP internet service provider : WAN을 서비스하는 업체 kt lg sk

### 패킷 교환 네트워크

packet : 송수신 되는 데이터의 단위<br>
payload : 데이터<br>
header : 어디로 보내고 어떻게 처리할지의 정보<br>
trailer : 검증정보 프로토콜에 따라 없을 수도 있다.<br>

### 주소, 전송방식

주소 : 호스트를 특정할 수 있는 정보, IP주소 MAC주소

`유니캐스트 unicast` : 1-1 메시지 전송 방식<br>
`브로드캐스트 broadcast` : 1-ALL 메시지 전송 방식<br>
브로드캐스트 도메인 : 브로드캐스트가 전송되는 범위, 같은 LAN에 속해있다고 본다.<br>
멀티캐스트 multicast : 네트워크 내의 동일 그룹에게만<br>
애니캐스트 anycast : 가장 가까운 호스트에게


## 패킷을 주고받는 과정

`프로토콜 protocol` : 네트워크 통신을 주고받는 노드간의 규칙, 방법
> IP ARP ICMP TCP UDP DHCP DNS HTTP SSL/TLS HTTPS

네트워크 참조 모델 : 통신이 이루어지는 단계를 계층적으로 표현한 것

### OSI 모델

OSI 7계층
> 물리 - 데이터링크 - 네트워크 - 전송 - 세션 - 표현 - 응용

물리 계층 : 비트 신호를 주고받는 계층, 신호를 유무선 통신 매체를 통해 운반<br>
데이터 링크 계층 : 같은 LAN에 속한 호스트끼리 정보를 주고받는 계층, MAC주소를 사용, 하드웨어와 밀접<br>
네트워크 계층 : 네트워크간 통신, LAN을 넘어 다른 네트워크와 통신하기 위한 계층, IP 주소 필요<br>
전송 계층 : 신뢰성 있는 전송을 가능하게함, 포트를 통해 응용프로그램과 다리역할을 수행 TCP UDP 포함됨<br>
세션 계층 : 응용 프로그램의 연결상태인 `세션`을 관리<br>
표현 계층 : 인코딩, 압축, 암호화 등<br>
응용 계층 : 네트워크 서비스를 제공하는 계층, HTTP HTTPS DNS 등 포함


TCP/IP 모델
> 네트워크 엑세스 - 인터넷 - 전송 - 응용

네트워크 엑세스 계층 : 물리 계층+데이터링크 계층
인터넷 계층 : 네트워크 계층
전송 계층 : 전송 계층
응용 계층 : 세션 계층 + 표현 계층 + 응용 계층

### 캡슐화 역캡슐화

`캡슐화 encapsulation` : 하위 계층으로 내려갈수록 헤더 혹은 트레일러를 덧붙힌다.<br>
`역캡슐화 de-encapsulation` : 상위 계층오로 올라갈수록 헤더 및 트레일러를 제거한다.

데이터 or 메시지 - > 세그먼트(TCP) / 데이터그램(UDP) -> 패킷 -> 프레임 -> 심볼 or 비트
