# 운영체제 개요
운영체제 = `커널 kernel`
## 자원할당 및 관리

컴퓨터 프로그램 실행에 필요한 SW자원 Data, HW자원 CPU, MEM, SSD등을 관리

간단한 목차
- CPU 스케줄링
    - 메모리 관리
    - 파일 관리
    - 프로세스 / 스레드 관리


## 시스템콜, 듀얼모드

- 커널 영역 : OS가 적재된 메모리 영역
- 사용자 영역 : 응용 프로그램이 적재된 메모리 영역
- `시스템콜` : 사용자 모드에서 커널모드의 기능을 사용하기 위한 인터페이스
- `인터럽트` : CPU의 작업을 멈추고(복사해둠) 우선 처리할 수 있도록 하는 것

---

`듀얼모드` : 운영체제의 코드를 사용하는 커널모드 모드, 응용 프로그램을 사용하는 사용자 모드

- SW Interrupt<br></t>
    SW Interrupt발생 -> 커널모드 진입 -> OS 코드 실행 -> 사용자모드 전환
