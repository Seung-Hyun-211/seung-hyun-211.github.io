## 코드 읽기

숙련된 프로그래머는 코드를 처음부터 한 줄씩 읽기보다 먼저 훑어보며 구조를 파악한다. 원문 노트에서는 코드 읽기 시간 중 상당 부분을 전체 내용을 빠르게 스캔하는 데 쓴다고 정리했다.

### 코드 읽기의 텍스트 전략

- 기존 지식을 활성화한다. 코드를 먼저 훑고 문법과 개념을 파악해 장기 기억(LTM)의 지식을 불러온다.
- 이해 상태를 모니터링한다.
- 중요한 라인을 찾아 그 의미를 이해한다.
- 변수명이 주는 힌트를 활용한다.
- 변수와 연관된 연산을 나열해 동작을 시각화한다.
- 코드의 목적과 기능을 질문한다.
- 코드의 동작을 자신의 언어로 요약한다.

## 문제 해결과 멘탈 모델

상태표나 의존 그래프 같은 모델은 코드가 동작하는 방식을 파악하는 데 도움이 되며, 머릿속에서 기억하고 처리해야 하는 인지 부하를 줄여준다.

멘탈 모델은 현재 시스템이 어떤 상태인지 이해하고 다음 동작을 추론하는 데 쓰인다. 작업 기억이나 LTM에 있는 기존 모델은 새 모델을 만드는 데 도움을 주며, 단순한 모델일수록 구성하기 쉽다.

개념적 기계는 복잡한 코드나 물리적 시스템을 추상화해 동작을 이해하는 모델이다. 스키마는 정보를 저장하는 지식의 틀로, 새로운 정보는 기존 스키마의 빈 부분에 연결된다.

## 생각의 오류를 다루기

- 오개념은 사실과 다른 내용을 사실이라고 확신하는 것이다.
- 개념 변화는 기존 스키마에 새 정보를 덧붙이는 데 그치지 않고, 잘못된 모델 자체를 바꾸는 과정이다.
- 알고 있는 내용도 틀릴 수 있음을 열어두고, 흔한 오개념을 점검하며 다른 프로그래머의 의견을 구한다.
