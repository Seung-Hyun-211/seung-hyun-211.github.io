## 테스트 글

이 글은 `_posts` 폴더에 Markdown 파일을 추가했을 때 GitHub 블로그에 표시되는지 확인하기 위한 글입니다.

### 작성 흐름

1. Markdown 파일 작성
2. Git에 추가
3. `main` 브랜치에 커밋 및 push
4. GitHub Pages 자동 배포

```text
파일 작성 → git add → git commit → git push → Pages 배포
```

본문이 정상적으로 표시되면 이후에는 같은 형식으로 글을 추가하면 됩니다.
